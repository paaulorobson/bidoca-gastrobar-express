# Bidoca Gastrobar & Drinks — Landing Page

Implementação em Next.js (App Router), React, TypeScript e Tailwind CSS.

## Executar

```bash
npm install
npm run dev
```

Abra http://localhost:3000.

## Personalização

- Edite textos e links em `app/page.tsx`.
- Substitua as fotos ilustrativas em `public/images/` por imagens autorizadas do estabelecimento.
- Confira o número de WhatsApp e os horários antes de publicar.
- O mapa utiliza Google Maps incorporado por endereço.

O layout de referência foi fornecido pelo cliente; as fotografias recortadas da referência são usadas como imagens temporárias para manter a composição visual.
